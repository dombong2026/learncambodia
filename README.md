# Learn Cambodia

International language-learning platform — foundation **v0.0.1**.

- **Website:** https://learncambodia.com
- **Author:** Ton Samith (https://tonsamith.com)
- **Repository:** https://github.com/dombong2026/learncambodia
- **Stack:** Laravel 13, PHP 8.3+, Tailwind CSS, TypeScript, JavaScript; optional independent Python services
- **Status:** Initial project bootstrap. No production deployment has been performed.

Learn Cambodia organizes English learning, proficiency-test preparation, teacher development, and specialist English using clear course taxonomy and the CEFR A1–C2 framework.

> Names such as IELTS, TOEFL, TOEIC, Cambridge English qualifications, Duolingo English Test and PTE are used descriptively. This project is **not** claiming to be an official or authorized test center or provider of third-party qualifications.

## Development

Project implementation will be proposed through pull requests and reviewed before deployment. Initial release starts with the category catalogue, authentication, accessible public headers and footer, and structured database schema.
