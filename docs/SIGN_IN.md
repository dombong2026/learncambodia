# Sign-in methods

Password sign-in remains available. In System Settings → Security, administrators can register passkeys and enroll an authenticator app. Other users can open Sign-in and security from their profile. Verify WebAuthn over the production HTTPS origin with APP_URL set to https://learncambodia.com. A password confirmation is required before changing security methods. Enrollment requires scanning the QR code and verifying a six-digit code. Save the recovery codes outside the site.

For Google sign-in, create a Web Application OAuth client and register https://learncambodia.com/sign-in/google/callback as an authorized redirect URI. Set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, and GOOGLE_SIGN_IN_ENABLED=true in the server environment and rebuild Laravel's configuration cache. Existing accounts must connect Google from their account settings. Email matches alone do not link accounts. New Google registrations require a verified Gmail or Google Workspace email and terms acceptance. They create student accounts. Users who created their account through Google can set a local password through LearnCambodia's password-reset flow before changing security settings.
