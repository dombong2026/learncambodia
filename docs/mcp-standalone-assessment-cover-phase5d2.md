# Phase 5D.2 — direct assessment cover upload

One new MCP tool: upload_draft_assessment_cover. Requires an owned MCP-created free standalone draft quiz/exam, empty cover, current version, UUID and alt text. Canonical base64 PNG/JPEG/WebP, 1920 x 1080, maximum 512 KiB decoded input, 2 MiB output. Shared validated course-cover pixel re-encoder; PNG transparency retained, JPEG/WebP normalized to JPEG. Local managed storage only, conditional creation and post-transaction orphan cleanup. Dedicated mcp:assessment-media scope requires assessment and media (and curriculum), prior six scopes remain valid. Independent production acceptance and enable flags default false; rehearsal false in production. No migrations, dependencies, arbitrary file upload, URLs, replacement, publishing, pricing or learner changes. Live acceptance must use new empty-cover drafts, not QA 224/225 or course 30.
