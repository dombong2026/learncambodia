# Phase 5D — standalone assessment rehearsal

Based on deployed Phase 5C.1. Seven new tools: list type IDs, inspect owned draft, create native free standalone quiz/exam, update settings, append/replace questions, attach existing owned library image. Dedicated mcp:assessment consent, default-off rehearsal gate, production closed. New ownership table records only MCP-created assessments; no existing assessment is claimed or backfilled. Reads and writes reject published, inactive, deleted, course-linked, paid, other-owner or attempted/assigned assessments. Current unpublished state only; no historic-publication tracking in native schema. Existing scopes remain supported and can be combined with assessment scope. Question formats: choice, reading, boolean, order, fill, short; native scoring validator. Quiz 1–50 questions / 1–30 minutes; exam 1–200 questions / 1–240 minutes; attempts 1–10; passing percent 1–100. Settings updates preserve existing questions and cover; version and receipt guards protect against stale/duplicate writes. No pricing, publication, student attempts, access grants, rich/media question edits, deletion or direct image upload. Guest controls are not present in this pinned native model; verify production overlay and add separately. Direct cover upload is a separate media acceptance step. No production migration or activation until CI and operator acceptance.
