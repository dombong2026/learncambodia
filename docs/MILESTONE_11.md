## Design and responsive requirements

The ten supplied JPEG references show two separate screen concepts placed side by side in a single image. This implementation **does not split a website page into two narrow columns**. Each new page is a single scrolling document with full-width section backgrounds, up to 1600px content width and flexible responsive grids. Cards can be arranged in grids inside wide sections; they are not two competing page shells.

Reusable Blade components:
- `resources/views/components/learning-hero.blade.php`: continuous navy/gold hero, screen-level breadcrumbs, responsive stats and optional real actions.
- `resources/views/components/learning-section.blade.php`: consistent edge-to-edge section background, heading, supporting text, responsive content container.
- `resources/views/components/learning-card.blade.php`: unified education card, consistent icons, real links, accessible text.
- Existing global `layouts/public.blade.php`, `partials/header.blade.php` and `partials/footer.blade.php` are preserved unchanged.

## Privacy, licensing and education constraints

- Only `ContentEntry(type=post,status=published)` is available to public readers; private drafts never render.
- Optional author attribution uses a separately approved, consented instructor profile, never a private account email.
- Courses use existing `Course::discoverable()` publication and category eligibility checks.
- Correct options, explanations and individual quiz questions are **not** exposed by exam catalog or course exam preview. Quizzes are accessed through existing authorized `StudentPracticeController` ownership and attempt limits.
- Focused lesson text is accessible only to the student owning an **approved enrollment** for a currently published course. All progress actions use existing `StudentProgressController` and `LearningAccess` protections.
- Recommendations match currently approved subject categories from the student's own enrollments and exclude already enrolled courses; they are not generated by AI or high-stakes psychological/proficiency prediction.
- Trophy milestones use only the user's own enrollment, completion, quiz submission and passed-quiz records; not public user rankings or invented points.
- Instructor course information and authored homework list are scoped to the signed-in active instructor's own assignments and records. Publishing and grading continue through the existing workflows.
- The upload screenshot is a **visual design reference only**. No simulated upload progress bar, premium price option, KHQR payment, downloadable files, file attachments, unverified maps, copied institutional seals, Telegram conversations, live classes or actual video player are presented as functional. File/media ingestion requires a separate scanner, rights-approval, storage, authorization and hosting acceptance milestone.
- Protected underage student identities and private academic records are never included in public rankings.
