# Phase 5D.3A — native advanced assessment authoring

Two tools under independent mcp:assessment-advanced authorization: list_draft_assessment_audio (owned private exam-context audio metadata only) and append_draft_advanced_assessment_questions (native listening, writing, speaking, Likert). Native manual grading is configured only; learner submission/grade tools not exposed. Existing six/seven-scope tokens remain usable. Independent production flags default false. Native question limits 50/200, at most 10 speaking questions, Likert unscored with native points placeholder 1. Append preserves instructions, existing questions, media links, and cover; legacy replacement remains blocked for rich/manual/audio content. Existing exam audio must be uploaded by the authorized admin through the native web editor. No direct audio upload, remote URL retrieval, arbitrary HTML, grading, publication, or student data. Native model, main branch, and authenticated attempt routes at the pinned baseline have no guest participation flag or unauthenticated attempt engine. Guest access requires a separate reviewed learner-side design (free published standalone only, session-bound attempt identity, limits, CSRF, throttles, audio authorization, expiration and scoring) and verified production baseline. Do not deploy a no-op guest flag or bypass the existing account middleware.
