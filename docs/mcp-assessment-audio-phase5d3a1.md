# Phase 5D.3A.1 — direct listening audio upload

Adds upload_draft_assessment_audio under independently gated mcp:assessment-audio (requires assessment-advanced and assessment). Existing eight-scope tokens still work. One atomic upload plus listening-question append, owned MCP-created free unpublished standalone assessment only. No unclaimed audio staging, remote URL, overwrite, public access, learner grading, publication or deletion. Private exam context, native pivot, native playback authorization. File bytes excluded from receipt/audit; SHA-256 input digest only. Version CAS, UUID replay, quiz/exam cap, conditional local create and post-authorization cleanup. Canonical RIFF PCM WAV only (16-bit, 1/2 channels, 8–48 kHz, 0.1–30 s, <=512 KiB including header, no extra chunks). Rebuild header and validate exact PCM length and libmagic MIME. No external decoder required. Other audio formats supported by native existing-media attachment but direct compressed formats deferred until safe decoding/re-encoding can be verified. R2/S3 disabled. No schema or dependency changes. Default production gates false.
