# Phase 5A.1 — production curriculum authorization

Separate `mcp:curriculum` consent is required in addition to exact read/write scopes. Existing read/write tokens retain existing permissions and receive an insufficient-scope challenge for native curriculum. Both production acceptance and enabled switches default false; the rehearsal switch must be false in production. Existing selected-admin, verified email, 2FA, signed Passport token, client, audience, revocation and ownership checks remain mandatory. No publication, replacement, upload or deletion. Deploy source disabled, confirm consent and signed token transport acceptance, then explicitly enable gates and obtain fresh consent. Client support for the new scope must be verified before importing content. No database migrations required.
